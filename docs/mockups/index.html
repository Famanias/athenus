Why do Transformer architectures scale the dot-product attention scores by 1/sqrt(d_k)?
🦉

Transformers divide dot-product attention scores by $\sqrt{d_k}$ because for large vector dimensions $d_k$, the magnitude of the dot product grows large. This forces the Softmax function into regions with extremely small gradients, leading to vanishing gradient problems during backpropagation.

Attention(Q, K, V) = Softmax( (Q * K^T) / sqrt(d_k) ) * V
