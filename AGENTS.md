# AGENTS.md

This file documents conventions for AI coding agents working in this repo.

---

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (`github.com/Famanias/athenus`); engineering skills use the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels are used as their own names: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout — `docs/CONTEXT.md` is the project memory, and `docs/adr/` holds architectural decisions. See `docs/agents/domain.md`.
